Lindy Classic8 (32657)
Power cycles use the PDU's native OFF/ON function, so a cycle can finish even when the NAS, Homebridge or network path is one of the outlets being restarted.
Connection
Leave blank to use the read community.
Used for the PDU-native OFF/ON command.
Power cycle controls
Seconds used temporarily for both the selected outlet's OFF and ON delay. Default: 1 second.
Example: Power Cycle Rack Fans.
With 1 second: outlets 1-8 switch OFF one per second, then return ON in the same 1-8 order one per second.
Individual power-cycle switchesExpose a momentary Power Cycle control for each enabled outlet.
Power Cycle EverythingExpose the autonomous all-outlet sequence control.
Permanent on/off switchesOptional. Leave disabled to reduce the chance of accidentally leaving equipment powered off.
Outlet overrides Optional

All eight outlets are exposed by default and use the names stored in the Classic8. Use a row below only when you want to rename an outlet in HomeKit, change its individual cycle delay, or hide it.

Advanced network & polling settings
SNMPv1 community strings and the Classic8 HTTP Basic login are not encrypted on the wire. Keep the PDU and Homebridge on a trusted LAN/VLAN and do not expose either management interface to the internet.
